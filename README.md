# 🤖 AI Study Assistant

A simple Python-based study assistant designed to help students organize their studies, create study plans, save notes, and get answers to common study questions.

## ✨ Features

* 📚 Study subject planner
* 📝 Study notes
* 🤖 Question-answer assistant
* ⏰ Study planning
* 💡 Simple study tips
* 🎓 Student-friendly interface

## 📂 Project Files

| File              | Description                    |
| ----------------- | ------------------------------ |
| `main.py`         | Main study assistant           |
| `study_plan.py`   | Creates a simple study plan    |
| `notes.py`        | Adds and displays study notes  |
| `ai_assistant.py` | Answers common study questions |

## 🛠️ Technologies Used

* Python
* GitHub
* Basic Python programming concepts
